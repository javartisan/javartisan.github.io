SmolLM 微调学习大纲

5 周把这条链跑通，并在本仓库里找到对应代码与阅读材料：

Pretraining → Base → SFT → LoRA → QLoRA → DPO → Reasoning

详细每日任务见 学习计划.md。材料索引见 材料/README.md。

设备：Intel Mac + PyTorch 2.2.2 时，第 1 周用 CPU 即可；更大模型按计划降配。

每周目标

周 大纲目标 本仓库怎么落地
第 0 阶段 分清 Encoder / Decoder / tokenizer encode 精读问答流程文档 + scripts/print_tokens.py
第 1 周 Transformer、Tokenizer、Dataset、Forward、Loss、Backward learn/week01/ 12 个脚本 + scripts/sft001.py
第 2 周 CPU vs MPS、内存、batch size learn/week02/ 01～07（MPS 不可用则 CPU 不同 batch）
第 3 周 为何不必更新全部参数（LoRA） scripts/sft001.py 的 LoraConfig
第 4 周 量化 + LoRA 如何省显存（QLoRA） 原理为主，本机工具链可能不完整
第 5 周 偏好对齐与偏好数据（DPO） 手写 chosen/rejected，对照 SFT

第 1 周：材料 × 代码对照（本周重点）

一条训练链：

文本 → Tokenizer → input_ids → Embedding+Decoder → logits
     → Loss → Backward → 参数更新
日 学什么 阅读材料 必跑脚本（仓库根目录）
Day 1 token、id、BPE、特殊符号 tokenizer 结构、知识体系 §1 learn/week01/01～05
Day 2 prompt / completion、训练/测试分离 data/train.jsonl、data/test.jsonl 06_read_dataset.py
Day 3 __call__、mask、Embedding 查表、logits 问答流程 §1/8/9、知识体系 §2 07、08；可选 learn/py/call.py
Day 4 train()、Dropout、backward、step 微调笔记 §5、知识体系 §3 09；可选 learn/py/dropout.py
Day 5 messages、chat_template、Instruct 微调笔记 §1–2 10_sft_messages.py + 通读 scripts/sft001.py
Day 6 Reference、NLL、字面重合 知识体系 §5 11_eval_metrics.py、scripts/eval_compare.py
Day 7 把 8 个框串起来 知识体系速记 + 代码导读 12_week1_chain.py

正式训练/评测入口仍在 scripts/（sft001.py、eval_compare.py），learn/week01/ 是把概念拆开看的练习。

验收（对照大纲）

第 1 周结束应能：

  • 讲清训练一步的 8 个框，并指出对应 learn/week01 脚本
  • 区分 tokenizer encode 与 Transformer Encoder
  • 说明 model.train() 不是开始训练，backward 写梯度、step 才改权重
  • 知道本项目 prompt/completion → messages → chat_template

5 周结束应能把完整知识链讲给另一个初学者，并在全量 / LoRA / QLoRA 之间按内存做选择。
