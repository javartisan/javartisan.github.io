SmolLM 微调学习计划（基础加强版）

依据：学习大纲.md
材料总览：材料/README.md
适用：基础较薄弱的初学者
目标：按周落地实践；第 1 周必须把概念对到 learn/week01/ 脚本上

设备提醒：你当前是 Intel Mac + PyTorch 2.2.2。
- 第 1 周以 CPU 为主即可
- 第 2 周再测 MPS（若本机 GPU/驱动支持）
- 360M / 1.7B 若内存不够，可先用 135M 把概念跑通，再升配

运行约定：下列 python ... 均在仓库根目录执行，并先 source venv/bin/activate。

0. 学习原则（先读这 5 条）

  1. 先概念，再代码，再改参：每学一个词，都要能用自己的话讲一遍。
  2. 每天输出一个“小结论”：写在笔记里，避免只看不做。
  3. 疑虑优先消掉：Encoder/Decoder 混淆不解决，后面 LoRA/DPO 会更懵。
  4. 本仓库是实验室：所有概念尽量在本项目文件里找到对应物。
  5. 完整知识链记住这句：
    Pretraining → Base → SFT → LoRA → QLoRA → DPO → Reasoning

最终要掌握的知识链（对照大纲）

Pretraining（海量文本预训练）
    ↓
Base Model（会续写，不一定会答题）
    ↓
SFT（监督微调：学会按标准答案回答）
    ↓
LoRA（只训练少量适配器参数）
    ↓
QLoRA（量化底座 + LoRA，更省显存）
    ↓
DPO（偏好对齐：更好回答 vs 更差回答）
    ↓
Reasoning（更复杂推理能力，后期拓展）

第 0 阶段（建议先做 2～3 天）：扫清基础疑虑

大纲里没写，但对你很关键。基础弱时不要急着进第 1 周改大模型。

目标

弄清下面这些“最容易混”的点：

  • tokenizer encode ≠ Transformer Encoder
  • Decoder 叫解码器，但层内传的是向量
  • 没有独立 Encoder，文本照样能变成向量
  • BERT / BART / LLM 结构差异

  • 第 10 节：一张总图与速记卡片
  • 动手：
  • 运行 python scripts/print_tokens.py "什么是 Java interface？"
  • 看 token 与 input_ids
  • 自测：
  • 能否默写出问答完整流程（从问题到 decode）？

Day 0-2：Encoder / Decoder 职责

  • 第 6 节：Encoder 与 Decoder 职责区别

Day 4：Loss + Backward + 参数更新

第 4 周：QLoRA（量化 + LoRA）

大纲目标：理解如何降低大模型微调的显存/内存需求。

现实约束

  • QLoRA 在 NVIDIA CUDA 生态最成熟；Mac 上工具链可能不完整。
  • 本周以原理 + 条件允许时的小实验为主，不硬通。

本周总目标

建立“先压缩底座，再挂 LoRA”的意识。

建议日程

Day 1～2：概念学习

  • 学：
  • 量化是什么（如 4-bit：用更少比特存权重）
  • QLoRA = 量化底座（通常冻结） + LoRA 训练
  • 笔记对比：
方法 底座怎么存 训练什么 省什么
全量微调 高精度全参数 全部参数 不省
LoRA 高精度底座 小适配器 省可训练参数/部分显存
QLoRA 低比特底座 小适配器 进一步省显存

  1. tokenizer encode 和 Transformer Encoder 不是一回事
  2. 问答 LLM 通常没有独立 Encoder

  8. LoRA 训补丁；QLoRA 先量化再训补丁
  9. model.train() 只换挡；backward 阅卷、step 改作业
  10. 大厂与脚本同一套公式；评测是多层门禁，没有一张统考卷
