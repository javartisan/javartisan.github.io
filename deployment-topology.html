评审时按这三条链路讲

① 登录浏览器 → Nginx → mtf-web / mtf-server:8899 → 浏览器跳转国泰 SSO（A）→ 回写会话。不经过 Agent、数据层、知识库（B）。
② 业务操作浏览器 → Nginx → mtf-server → 数据层（⑤ JDBC / S3 / Redis）。不经过 Agent 与国泰出网。
③ 调用 Agentmtf-server → Nacos 查 AgentCard → Agent 运行区（③）→ 模型（④）；同时可走数据层（⑤）与国泰知识库（B）。Agent 禁止直连数据层（⑥）。
