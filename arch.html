外部服务集成区 · 国泰侧

系统出站访问。国泰不反向打入内网。SSO、知识库、SIT 测管与 UAT 自动化均在此侧。

统一登录 SSO 出网 HTTP · 同一套国泰统一登录
  • 浏览器通道（不经 mtf-server）
  • A1/authorize 打开统一登录页
  • A2用户在国泰页输入账密完成本地认证
  • A3302 回调门户 redirect_uri，附带 authorization code
  • 服务端通道（仅 mtf-server）
  • A4/token　用 code 换 access_token
  • A5/userinfo　拿到身份标识
  • A6JDBC 查统一库，补齐用户信息 / 权限
